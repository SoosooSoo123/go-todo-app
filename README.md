# 📝 Todo App (Go + GORM + MySQL)

این یک پروژه مدیریت کارهای روزمره (Todo List) است که بخش بک‌اند آن با زبان **Go** و با استفاده از **GORM** به دیتابیس **MySQL** متصل شده و دیتای فرانت‌اَند را مدیریت می‌کند.

---

## 📊 ساختار دیتابیس (Database Schema)

پروژه از قابلیت `AutoMigrate` در GORM استفاده می‌کند. جدول اصلی سیستم `todos` نام دارد که ساختار ستون‌های آن در MySQL به شرح زیر است:

| نام ستون (Field) | نوع داده (Type) | توضیحات |
| :--- | :--- | :--- |
| `id` | INT (Primary Key) | شناسه یکتا و خودکار تسک |
| `title` | VARCHAR(255) | عنوان یا متن کاری که باید انجام شود |
| `completed` | BOOLEAN | وضعیت انجام شدن (true) یا نشدن (false) |
| `created_at` | DATETIME | زمان دقیق ساخت تسک |
| `updated_at` | DATETIME | زمان آخرین ویرایش تسک |

---

## 🛣️ اندپوینت‌های API (API Endpoints)

تمام درخواست‌ها به صورت JSON مبادله می‌شوند. سرور روی پورت `8080` به درخواست‌ها پاسخ می‌دهد.

| متد (Method) | مسیر (Endpoint) | توضیحات | نمونه درخواست (Request Body / Query) |
| :--- | :--- | :--- | :--- |
| **GET** | `/tasks` | دریافت لیست تمامی تسک‌ها | بدون پِی‌لود |
| **POST** | `/tasks` | ساخت و ذخیره یک تسک جدید | `{"title": "خرید کتاب Go", "completed": false}` |
| **PUT** | `/update` | ویرایش متن یا وضعیت تسک | `{"id": 1, "title": "خرید کتاب", "completed": true}` |
| **DELETE** | `/delete` | حذف یک تسک بر اساس ID | نیاز به کوئری استرینگ: `/delete?id=1` |
